# Hackathon Release Checklist

- [ ] Replace team submission placeholders and verify organizer's exact required format.
- [ ] Test from a clean clone on a second machine if possible.
- [ ] Run frontend build/lint and backend fmt/check/test.
- [ ] Run the API smoke test and perform the manual UI checklist.
- [ ] Capture 3–5 screenshots of the real current application and a 2–3 minute demo video if required.
- [ ] Ensure every demo listing/metric/rate is described as simulated.
- [ ] Include repo URL, demo URL, team roles, track, problem statement and short pitch in the submission portal.
- [ ] Remove secrets and personal data from terminal output and screenshots.
- [ ] Do not claim live GPU provisioning, blockchain escrow, verified SLA or real provider integrations unless these are implemented and tested.
- [ ] Review license terms for third-party visuals and packages; agree on a project license as a team.
